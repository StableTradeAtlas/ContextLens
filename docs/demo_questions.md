# Demo Questions

## 追一个人 / Trace a Person

- 盛宣怀与上海的铁路、银行和航运有什么联系？
- 张骞这一人物如何出现在后世文献与丝路叙事中？
- 鲁迅在上海期间与哪些人物、地点和刊物相关？
- How was Sheng Xuanhuai connected with Shanghai railways, banks, and shipping?

## 寻一处地 / Explore a Place

- 外滩某栋历史建筑经历过哪些机构和人物？
- 我家旧地址附近发生过什么历史事件？
- Which institutions and trade networks can be traced from a historic building on the Bund?

## 城市记忆漫游 / City Memory Walk

- 南京路的百货公司、报刊广告和市民生活可以串成怎样的城市记忆路线？
- 张爱玲的作品、出版机构和上海公寓能如何形成文学地景档案？
- 老照片里出现的一条上海马路，如何通过地名志、道路数据和报刊材料复核？
- How can Nanjing Road department stores, newspaper ads, and everyday life become a city-memory route?

## 家族线索寻踪 / Family Memory Trace

- 如果我只知道家谱中的一个姓名和上海旧地址，下一步该查哪些证据？
- 校友录、旧居和报刊索引能如何帮助确认一个普通人的城市经历？
- 家谱中的祖籍、迁居地和亲属关系，哪些可以写成事实，哪些必须保留为待考？
- If I only know a genealogy name and an old Shanghai address, which evidence should I check next?

## 还原一件事 / Reconstruct an Event

- 近代上海通商事件如何连接海关、商人、银行和城市空间？
- 丝绸之路贸易如何依赖外交、边疆治理与使节制度？
- How did modern Shanghai treaty-port events connect customs, merchants, banks, and urban space?

## 读懂一份文献 / Read a Document

- 一条近代报刊索引如何追溯到人物、地点和事件？
- 盛宣怀档案中的一条题名如何连接到机构和城市基础设施？
- How can a newspaper index entry be traced to people, places, and events?

## 上海与世界专题 / Shanghai and the World

- 一张晚清汇票如何连接商人、银行、口岸与海外贸易？
- 历史上的银两、纸币与银行制度如何支撑跨区域贸易信任？
- What historical institutions help explain today's Belt and Road settlement challenges?

- 实体链接 / Entity links
- 主张级证据台账 / Claim-level evidence ledger
- 反证与空白 / Counter-evidence and gaps
- 继续追问 / Follow-up routes
- 故事模式 / Story mode
- 研究模式 / Research mode
- 证据质量闸门 / Evidence quality gates
- 调查回放 / Investigation replay
- 数据使用收据 / Data-use receipt
