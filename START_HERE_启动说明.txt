文脉镜 ContextLens｜老师验收启动说明
====================================

一、启动

1. 先完整解压 ZIP，不要直接在压缩包预览中运行。
2. Windows：双击 START_HERE_WINDOWS.bat
3. macOS：双击 START_HERE_MAC.command
4. 浏览器会自动打开 http://127.0.0.1:8765

二、电脑要求

- Python 3.10 或更高版本
- Chrome、Edge、Safari 或 Firefox 等现代浏览器
- 不需要安装 Node.js
- 不需要配置 API 密钥；包内的离线数据可直接完成演示
- 联网时可加载在线历史/现代地图；断网时核心资料与降级地图仍可使用

三、推荐验收输入

- 霞飞路436号，年代选择“1930年代”
- 南京路百货公司，年代选择“1940年代”
- 火星路9999号（验证找不到证据时不会编造）

四、停止

在启动窗口中按 Ctrl+C，或关闭启动窗口。

五、常见问题

- 端口 8765 被占用：程序会自动尝试附近的可用端口并打开浏览器。
- macOS 提示无法打开：右键 START_HERE_MAC.command，选择“打开”。
- 未自动打开浏览器：手动访问启动窗口中显示的 http://127.0.0.1:端口。
- 提示找不到 Python：从 https://www.python.org/downloads/ 安装 Python 3.10+ 后重试。

项目说明、数据边界和测试方式请参阅 README.md。
